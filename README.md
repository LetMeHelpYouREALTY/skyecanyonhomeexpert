# Skye Canyon Homeowner Resource Hub

A comprehensive community lifestyle website for Skye Canyon, Nevada residents featuring homeowner resources, community information, local guides, and contractor directories.

## 🏡 About

This is a **Resident Living & Homeowner Resource Hub** (NOT a home buying site) designed specifically for current Skye Canyon homeowners and residents. The site provides:

- **Homeowner Essentials**: HOA guides, maintenance tips, HVAC & pool care
- **Community Living**: Events calendar, amenities guide, restaurants, schools
- **Resident Resources**: Contractor directory, trash schedules, pet services, community groups

## 🎯 Target Keywords

- living in Skye Canyon Nevada
- Skye Canyon HOA rules explained
- best contractors Skye Canyon
- things to do near Skye Canyon
- Skye Canyon community events calendar

## 🚀 Getting Started

### Prerequisites

- Node.js 18.17.0 or higher
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

### Build

```bash
npm run build
npm start
```
